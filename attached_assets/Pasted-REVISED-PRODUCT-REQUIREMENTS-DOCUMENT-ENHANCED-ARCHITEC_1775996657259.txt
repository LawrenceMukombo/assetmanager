This Database Design Specification (DDS) defines the logical and physical database structure for the National Public Asset Management System (NPAMS). It provides the foundational data model required for software engineers to build the backend database, APIs, and business logic layers.

Multi-tenant national deployment

Normalization: Minimum 3NF to reduce redundancy.
Auditability: Timestamping and user tracking on all mutable tables.

Scalability: Designed for >500,000 asset records.
